Design and implement a cloud-native service to process the Enron Email 2015 dataset (available here https://www.cs.cmu.edu/~enron/enron_mail_20150507.tar.gz). Service should be able to ingest the dataset and provide metrics over HTTP. The following endpoints should be provided.
 
POST /start: start the ingestion
GET /status: returns the following info:
      - whether the ingestion is finished or not
      - total number of messages processed
GET /top-senders: returns the 10 top senders
 
The system should be runnable locally. Our preferred programming language is Go, but you want you can also use some other language.  You may use any freely-available 3rd party service or library to assist you. Code should be submitted using online code sharing services (e.g. GitHub).

 Feel free to use any AI tools as much as you want, but be prepared to present your solution and answer questions about it in the technical interview.
